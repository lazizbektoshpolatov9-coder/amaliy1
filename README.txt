STUDENT PORTFOLIO VA BOSHQARUV TIZIMI
O'rnatish yo'riqnomasi

TALABLAR:
- XAMPP yoki OpenServer
- PHP 7.4 yoki yuqori versiya
- MySQL 5.7 yoki yuqori versiya

O'RNATISH:

1. XAMPP ni ishga tushiring (Apache va MySQL)

2. portfolio.sql faylini import qiling:
   - phpMyAdmin ga kiring (http://localhost/phpmyadmin)
   - "Import" bo'limiga o'ting
   - database/portfolio.sql faylini tanlang
   - "Go" tugmasini bosing

3. Fayllarni joylashtiring:
   - Barcha fayllarni XAMPP htdocs papkasiga ko'chiring
   - Masalan: C:\xampp\htdocs\portfolio\

4. Brauzerda oching:
   http://localhost/portfolio/

5. Admin hisobi bilan kirish:
   Email: admin@portfolio.uz
   Parol: admin123

6. Yangi foydalanuvchi yaratish uchun:
   http://localhost/portfolio/register.php

ASOSIY IMKONIYATLAR:
- Foydalanuvchi ro'yxatdan o'tishi va kirishi
- Loyihalar qo'shish, tahrirlash, o'chirish (CRUD)
- Kategoriya bo'yicha filtrlash
- Loyihalar orasida qidirish
- Admin paneli (barcha foydalanuvchilar va loyihalarni boshqarish)
- Captcha himoyasi
- Session va Cookie bilan ishlash
- CSRF token himoyasi
